Carga de presupuesto (metas de venta)

  1. Descargue la plantilla de Excel y llene la hoja «Plantilla»: una fila por año, mes, vendedor y artículo.
  2. Columnas: Año, Mes, Línea, Líder, codVendedor, codArticulos, Proveedor, Incentivo (opcional), MetaUnidades y Minimo (opcional). Los códigos válidos están en la hoja «Catálogos».
  3. Súbala aquí: el sistema la revisa y le muestra una vista previa sin guardar nada. Si todo está bien, confirme para guardar.
  4. Todo o nada: si una fila tiene error no se guarda ninguna. Subir otra vez un año/mes/vendedor reemplaza sus metas anteriores.
